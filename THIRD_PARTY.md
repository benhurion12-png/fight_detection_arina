# Источник модели

В проект включена модель ppTSM Fight из экосистемы PaddleDetection / PP-Human, преобразованная из Paddle inference format в ONNX.

- Исходный проект: https://github.com/PaddlePaddle/PaddleDetection
- Документация: https://github.com/PaddlePaddle/PaddleDetection/blob/release/2.8/deploy/pipeline/README_en.md
- URL исходных весов, указанный в конфигурации PaddleDetection: https://videotag.bj.bcebos.com/PaddleVideo-release2.3/ppTSM_fight.zip
- Конвертер: https://github.com/PaddlePaddle/Paddle2ONNX
- Runtime: https://github.com/microsoft/onnxruntime

Текст лицензии исходного репозитория PaddleDetection сохранён в `licenses/PaddleDetection-LICENSE.txt`. Это указание происхождения сторонних компонентов, а не назначение лицензии авторскому коду KU Fight detection.
